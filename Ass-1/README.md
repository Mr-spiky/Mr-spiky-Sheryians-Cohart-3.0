# Loomé - Product Landing Page

This project is a responsive product landing page for "Loomé," a fictional brand specializing in high-quality cotton scarves. The design is based on a modern, clean aesthetic, focusing on a single product to create an elegant and immersive user experience.

## Features

- **Responsive Design**: The layout is fully responsive and adapts to various screen sizes, from mobile phones to desktops.
- **Modern UI**: Clean and minimalist design with a focus on typography and high-quality imagery.
- **Interactive Elements**: Hover effects on buttons and links to enhance user interaction.
- **CSS Flexbox and Grid**: The layout is built using modern CSS techniques for flexibility and alignment.
