## 🚀 Live Demo

Check out the live deployment of the project here: [Live Demo](https://www.mrspiky.me/Mr-spiky-Sheryians-Cohart-3.0/Ass-6/)

---

## ✨ Features

* **Premium Interactive UI:** Rich animations, smooth slider controls, and glassmorphism elements matching the original brand aesthetic.
* **100% Responsive Layout:** Seamless, mobile-first design optimized across various desktop, tablet, and mobile devices.
* **Modern Carousels & Lazy Loading:** Integrated Flickity for smooth product sliders and Lozad.js for performant image loading.
* **Rich Interactions:** Dynamic off-canvas menus, interactive cart drawer, and interactive customer review components.
* **Clean Semantic HTML:** Designed with high accessibility and SEO-friendly structure.

---

## 🛠️ Tech Stack

* **Structure:** HTML5 (Semantic tags, Alpine.js configurations)
* **Styling:** CSS3 (Custom properties/variables, responsive layouts, hover states, keyframe animations)
* **Interactions:** Vanilla JavaScript, GSAP (GreenSock Animation Platform) for page animations, Flickity slider, Lozad.js lazy loading
