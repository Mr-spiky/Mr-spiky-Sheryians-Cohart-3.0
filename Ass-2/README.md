# Sheryians Cohort 3.0 - Assignment 2: Landing Pages

This repository contains three distinct landing pages created as part of an assignment for the Sheryians Coding School's Cohort 3.0. Each landing page is in its own directory (`Easy`, `Medium`, `Hard`) and showcases different design and layout techniques.

## Live Demos

You can view the live versions of the landing pages here:

*   **Easy:** [Live Demo](https://www.mrspiky.me/Mr-spiky-Sheryians-Cohart-3.0/Ass-2/Easy/)
*   **Medium:** [Live Demo](https://www.mrspiky.me/Mr-spiky-Sheryians-Cohart-3.0/Ass-2/Medium/)
*   **Hard:** [Live Demo](https://www.mrspiky.me/Mr-spiky-Sheryians-Cohart-3.0/Ass-2/Hard/)

## Landing Pages Overview

### 1. Easy
A clean and minimalist landing page for a fictional company named "Bittel".

**Features:**
*   Simple, single-column layout
*   Centered content with a large background image
*   Clean typography

### 2. Medium
A stylish and modern landing page for a restaurant or bar menu, named "Gunaforycter".

**Features:**
*   Dark theme with accent colors
*   Card-based layout for menu items
*   Detailed "Chef's Special" section

### 3. Hard
A detailed and visually rich product page for an insect specimen, "Pachyteria equestris".

**Features:**
*   Split-screen layout
*   Vertical text for classification
*   Detailed product information grid
*   Interactive-like elements (toggles)

## Technologies Used

*   HTML5
*   CSS3
*   Google Fonts
*   Font Awesome (for icons in the 'Hard' project)

## How to Use

1.  Clone the repository:
    ```bash
    git clone https://github.com/Mr-spiky/Mr-spiky-Sheryians-Cohart-3.0.git
    ```
2.  Navigate to the project directory:
    ```bash
    cd "Mr-spiky-Sheryians-Cohart-3.0/Ass-2"
    ```
3.  Open the `index.html` file within any of the `Easy`, `Medium`, or `Hard` folders in your web browser to view the pages locally.
