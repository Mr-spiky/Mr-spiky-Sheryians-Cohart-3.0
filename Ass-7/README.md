## ⚙️ How it actually works (the lore)

### adding tasks 📝
type your task → pick a category → smash **Add** → it's on the list no cap

### editing tasks ✏️
hit the edit icon → change stuff up → save → updated bestie

### completing tasks ✅
checkbox goes brrr → task gets strikethrough → stats auto-update → dopamine hit unlocked

### filtering 🎛️
tab buttons at the top: **All / Done / Pending** → tasks filter instantly, zero page reload, pure DOM magic

### stats dashboard 📊
everything auto-calculates. total, completed, pending. even the progress bar moves. it's giving real-time.

### DOM concepts that got us here 🧠
we're not just building — we're **learning**:
- **Browser Rendering Pipeline** (HTML → Tokenize → DOM → CSSOM → Render Tree)
- **`input.value` vs `getAttribute('value')`** — live value vs static attribute
- **Event Bubbling vs Capturing** — interactive demo built right in the app
