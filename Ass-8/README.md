# FinTrack Pro 💰

> Assignment 8 — Sheryians Cohort 3.0

A personal finance tracking web app built entirely in the browser with **no backend required**. Track income, expenses, savings, and get a visual overview of your spending — all data persists via `localStorage`.

---

## 🔗 Live Demo

[https://www.mrspiky.me/Mr-spiky-Sheryians-Cohart-3.0/Ass-8/](https://www.mrspiky.me/Mr-spiky-Sheryians-Cohart-3.0/Ass-8/)

---

## ✨ Features

- 🔐 **User Auth** — Register & login system (localStorage-based, per user)
- 💳 **Add Transactions** — Log income or expenses with category, description, amount & date
- 📊 **Expense Chart** — Visual doughnut chart powered by Chart.js
- 🔍 **Search & Filter** — Quickly find transactions by keyword or type
- 🌗 **Dark / Light Mode** — Toggle theme with persistent preference
- 📱 **Responsive Design** — Works on desktop and mobile
- 🗑️ **Delete Transactions** — Remove any transaction from history
